# Contribuindo

Obrigado por melhorar o AICR Framework.

## Preparação

Requisitos: Git e Node.js 20 ou superior.

```bash
npm ci
npm run check
```

## Fluxo

1. Abra uma issue para mudanças relevantes de contrato ou política.
2. Crie uma branch curta e mantenha o escopo coeso.
3. Adicione testes para alterações de comportamento.
4. Execute `npm run check` e `npm run pack:check`.
5. Abra um pull request explicando motivação, risco e validação.

Não inclua código, diffs, relatórios ou fixtures que contenham segredos ou dados proprietários. Contribuições são licenciadas sob Apache-2.0.
